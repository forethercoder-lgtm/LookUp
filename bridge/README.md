# Мост для наушников

Браузер не имеет доступа к гироскопу наушников: систему движения отдаёт только нативным приложениям сама ОС.
Поэтому наклон головы на сайт передаёт маленькая программа-мост по `ws://127.0.0.1:8765`.

## Какие наушники подходят

Только те, что отдают движение системе. Для Apple `CMHeadphoneMotionManager` работает с AirPods (3-го поколения), AirPods Pro, AirPods Max и Beats Fit Pro
([Apple](https://developer.apple.com/documentation/coremotion/cmheadphonemotionmanager)). Более новые модели, вероятно, тоже, но это не проверено.
«Любые» наушники подключить нельзя: без датчика движения в наушниках гироскопа нет, а сайт не может прочитать его напрямую.

## Mac (macOS 14+)

```sh
xcode-select --install      # один раз
sh bridge/mac/build.sh
./bridge/mac/lookup-bridge
```

Наденьте наушники → на сайте нажмите «Наушники», затем «Старт» (камера + датчик) или «Без камеры».
Первый запуск может запросить доступ к «Движению и фитнесу».

Если программа падает или запрос не появляется (macOS привязывает разрешение к Terminal), запустите как приложение:

```sh
open --stdout /tmp/lookup-bridge.log "bridge/mac/LookUp Bridge.app"
```

Мост слушает только localhost. **Надёжнее всего локальная версия сайта:** `python3 -m http.server 8080` в корне проекта → http://localhost:8080.
С https-сайта Chrome блокирует `127.0.0.1` (Local Network Access): нужно разрешить доступ к локальной сети в запросе браузера. Safari блокирует `ws://` со страниц `https://` полностью.

> Мост написан без доступа к Mac и **не собирался и не запускался**. Последний проход (без запуска): порт задаётся через `NWListener(using:on:)` и интерфейс `loopback`, при отсутствии наушников мост ждёт, а не завершается, поток данных перезапускается при подключении, добавлена сборка `.app`. При первой сборке возможны правки компилятора.

## Windows и Android

- Windows: API движения наушников нет. Остаются камера и симулятор.
- Android: движение головы отдают наушники с поддержкой head tracking (например Pixel Buds Pro) как датчик `TYPE_HEAD_TRACKER` через Bluetooth
  ([Android Open Source Project](https://source.android.com/docs/core/audio/spatial)). Прочитать его может только нативное приложение; такого приложения у нас нет.

## Протокол: подключить любой другой источник

Сайту всё равно, откуда данные. Любая программа, которая шлёт по `ws://127.0.0.1:8765` текстовые кадры `{"pitch":градусы}` (можно `roll`, `yaw`, `t`), подойдёт.
Так можно добавить Android-приложение или другие наушники, если у них есть SDK.

## Симулятор (любая ОС, проверка сайта без наушников)

```sh
node bridge/fake-bridge.mjs            # обычный знак
node bridge/fake-bridge.mjs --invert   # проверка автоопределения знака
```

Сценарий: прямо → кивок вниз → норма → наклон 30° → норма, по кругу.
