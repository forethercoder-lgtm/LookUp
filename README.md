# LookUp

**Подними экран — голова поднимется сама.**
Подставка для MacBook (механика, без электроники) + браузерное приложение:

1. **Калькулятор** — вводите высоту платформы, получаете угол раскрытия крышки и наклон головы; есть «оптимальный пример» и рекомендуемая высота.
2. **Контроль** — кнопка «Старт»: камера (MediaPipe Face Landmarker) оценивает наклон головы относительно калибровки. Угол в норме (≤ порога, по умолчанию 15°) — тишина; выше порога дольше 2 сек — сирена, пока голова не вернётся.
3. **Эксперимент** — тесты «без» и «с» подставкой, сравнение и выгрузка CSV.

Проект сделан для FIZTEX Hackathon (STEM, «ErgoNeck»: ≤ 5 000 ₸, без электроники, 0–15°, подготовка < 30 сек). Приложение — измерительный стенд, а не часть подставки.

## Запуск локально

Windows: двойной клик по `start.bat` (нужен Python) → http://localhost:8080.
Любой статический сервер подойдёт; камера в браузере работает только на `localhost` или https.

Всё лежит в репозитории (`vendor/` — MediaPipe Tasks Vision 1.0.1, `models/face_landmarker.task`), сборки нет, интернет не нужен.

## Ограничения

- Угол головы — оценка по 3D-позе лица, не медицинское измерение. Зависит от света и камеры.
- Размеры экранов MacBook в калькуляторе приблизительные (`MACS` в `app.js`).
- Если при наклоне головы вниз угол уменьшается, нажмите «Инвертировать знак» (не проверено на всех камерах).
- Порог теста «≥ 90 % времени в зоне» выбран нами (`PASS_RATIO`).
- Браузер может замедлять неактивные вкладки: держите LookUp в отдельном окне.
