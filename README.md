# LookUp 🩺

**Подними экран — подними голову.** Держим шею в безопасной зоне 0–15°.

Две версии: **Mac** (`/mac/`) и **Windows** (`/windows/`, есть режим «Монитор»). Открывается на `/` с выбором системы.

## Что умеет

1. **Экран** — вводите только высоту платформы: получаете угол крышки (или наклон монитора) и наклон головы.
2. **Подготовка** при «Старте»: камера подсказывает «↔ Отодвиньте / Придвиньте экран», «⤴ Откройте / ⤵ Прикройте экран», «💡 Добавьте света», проверяет, что видны лицо и плечи. Расстояние до экрана измеряется по зрачкам и учитывается в расчёте.
3. **Контроль** — камера следит за головой (MediaPipe Face Landmarker) и ключицами/плечами (MediaPipe Pose). Всё хорошо — тишина; поза плохая дольше 2 сек — сирена, пока не исправится. Показывает, на сколько градусов подкрутить экран.
4. **Наушники** (Mac, AirPods) — гироскоп наушников точнее камеры и работает без камеры и в фоне. Нужен мост: [bridge/](bridge/README.md).
5. **Фон** — кнопка «🪟 Фон» открывает маленькое окно поверх всех окон (Chrome/Edge), чтобы можно было работать в других программах.
6. **Тест** — «без» и «с» подставкой, сравнение, CSV.

## Точность: что сделано

- Медиана по 5 отсчётам + сглаживание, гистерезис порогов (нет «дрожания» сирены), проверка неподвижности при калибровке.
- Голова повёрнута в сторону (> 40°) — угол не считается, сирена не воет.
- Знак угла определяется кивком; калибровка «смотрю вдаль».
- Если плеч не видно, наклон к экрану определяется по росту размера лица.
- Кадры читаются через MediaStreamTrackProcessor (работает и в фоновой вкладке), таймер — в Web Worker.
- Датчик наушников — приоритетный источник головы, камера — запасной.

## Запуск локально

Windows: `start.bat` (нужен Python) → http://localhost:8080. Камера работает только на `localhost` или https. Интернет не нужен (`vendor/` — MediaPipe, `models/` — модели лица и позы).

Страницы `mac/` и `windows/` генерируются из `template.html`: после правок шаблона выполните `node build.mjs`.

## Ограничения (честно)

- Углы — оценка по камере, не медицинское измерение; зависят от света и камеры. Оценка угла экрана, расстояния и пороги плеч подобраны без тестов на реальных людях.
- Мост для AirPods (`bridge/mac`) **не собирался и не запускался** — писался без Mac. Сайтовая часть проверена на симуляторе `bridge/fake-bridge.mjs`.
- На Windows нет способа получить гироскоп наушников; там — камера.
- Наушники лучше всего работают на **локальной версии сайта** (`start.bat` → http://localhost:8080). С https-сайта Chrome блокирует связь с `127.0.0.1` (Local Network Access) — нужно разрешить доступ к локальной сети в запросе браузера; в headless-проверке запроса нет, и соединение блокировалось. Safari блокирует `ws://` со страниц `https://` полностью.
- В MediaPipe Pose нет точек ключиц: линия ключиц строится по плечам и основанию шеи.
- Фоновое окно — только Chromium (Chrome/Edge). В скрытой вкладке без него браузер может замедлять страницу.
